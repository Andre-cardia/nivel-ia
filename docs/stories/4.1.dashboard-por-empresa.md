## Story
**As a** administrador do sistema,
**I want** um painel admin organizado por empresa (survey), com fluxo completo de cadastro → link → resultados separados por cliente,
**so that** eu possa gerenciar múltiplos clientes de forma independente, visualizando os diagnósticos de cada empresa separadamente.

## Acceptance Criteria

1. O Dashboard (`/admin`) exibe a lista de surveys (empresas) cadastradas — não assessments individuais — com card por empresa mostrando: nome da empresa, stakeholder, total de respondentes, média de score, status (ativa/inativa) e botão "Ver detalhes".
2. O Dashboard possui botão "Nova Pesquisa" que navega para `/admin/surveys/new`.
3. A sidebar do Admin exibe navegação com "Dashboard" ativo quando em `/admin`.
4. A página de criação de pesquisa (`/admin/surveys/new`) permanece como está — cadastra empresa + stakeholder e gera token único.
5. O link gerado pela pesquisa (`/q/:token`) exibe o nome da empresa na `Landing` — headline deve mostrar "Qual é o **Nível IA** da **{company_name}**?" em vez de "sua empresa".
6. A página de detalhe da survey (`/admin/surveys/:id`) lista os respondentes daquela empresa com: nome, cargo, pontuação, nível, e expansão de dimensões por respondente.
7. O campo "Empresa" na página de `Identification` é pré-preenchido com `survey.company_name` e desabilitado quando o acesso vem por link tokenizado.
8. Assessments salvos via link tokenizado devem registrar `survey_id` no banco.

### Query sugerida para Dashboard (Task 1.1 e 1.2)

```js
// Busca surveys com contagem de respondentes
const { data } = await supabase
  .from('surveys')
  .select('id, company_name, stakeholder_name, stakeholder_role, token, is_active, created_at, assessments(total_score)')
  .order('created_at', { ascending: false })

// Calcular média localmente:
const withStats = data.map(s => ({
  ...s,
  respondent_count: s.assessments.length,
  avg_score: s.assessments.length
    ? Math.round(s.assessments.reduce((sum, a) => sum + a.total_score, 0) / s.assessments.length)
    : null,
}))
```
